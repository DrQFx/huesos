Runnable Application Binary Interface    ISA 0.2    Specification
HuesOS 0.1

Спецификации:
    Ячейка - объект типа Value, хранящий любое значение и его тип.
    Фрейм (Frame) - объект, создающийся в момент вызова функции, хранящий
                    адрес возврата, локальные переменные и аргументы функции.
                    При возврате из функции полностью очищается.
    Operand Stack - основной стек, использующийся для выполнения каких-либо операций с информацией.
                    Не хранится в оперативной памяти RABI, существует отдельно.
    Frame Stack - второстепенный стек, используется для хранения фреймов и выполнения операций с ними. 
                  Не хранится в оперативной памяти RABI, существует отдельно.
    IP (Instruction Pointer) - индекс текущей инструкции.
    

Общая структура RABI ISA 0.2:
    .ra программа содержит соответствующие поля:
        Метадата: (Используется только планировщиком HuesOS)
            VERSION - версия исполняемого приложения,
            NAME - название
        Дата:
            Здесь инициализируются глобальные переменные, которые могут быть соответствующих типов:
                int,
                string,
                float,
                double,
                long,
                object,
                bool
        Код:
            Здесь содержатся все инструкции, функции и т. д.
        За пределами кодового сегмента может находится только инструкция "use",
        обычно объявляемая в самом начале программы, до секции метадаты.
    Структура программы:
        use "fs/system/libs/standard.ra"
        .info -Метадата-
            NAME : "Application"
            VERSION : 1
        .data -Дата-
            greeting : string | "Hello"
        .code -Код-
            ENTRY: -Точка входа-
                PUSH greeting
                CALL PRINT
                HALT

Доступные инструкции:
    Общее:
        use "..." -     Импорт библиотеки.
                        Находит файл по адресу "...", парсит инструкции, переменные
                        и добавляет в конец списка исполняемых инструкций.
        ENTRY: -        Точка входа в программу.
                        Перемещает IP на позицию ENTRY+1 до начала выполнения,
                        Обязательна для всех исполняеных программ.
        HALT -          Завершает выполнение программы.
                        Убивает процесс через планировщик HuesOS
        CALL ... -      Вызов функции/Системный вызов.
                        Совершает вызов функции либо системный вызов.
                        Системные вызовы:
                            CALL PRINT - выводит на экран верхушку стека,
                            очищаяя её.
        Метки:
            Метки позволяют объявлять функции, вызывать их, а так же
            прыгать в разные части кода во время выполнения программы.
            Метки объявляются так:
                НАЗВАНИЕ:
                    код
                    RET - необязательно
    Стек:
        PUSH ... -      Кладёт значение на вершину стека
        POP ...  -      Принимает адрес. Берёт вершину стека и записывает
                        её по этому адресу в памяти.
        SWAP     -      Меняет местами верхушку и следущее значение в стеке.
        DUP      -      Дублирует вершину стека.
        OVER     -      Копирует верхнее значение вниз через одно.
        DROP     -      Очищает вершину стека.
    Математика:
        ADD      -      Складывает два верхних числа стека и возвращает их сумму.
        SUB      -      Вычитает вершину стека из значения ниже, возвращает их разницу.
        MUL      -      Умножает два верхних значения стека.
        DIV      -      Берёт второе значение из стека и делит его на верхнее значение.
    Логика:
        EQ       -      Сравнивает два верхних значения стека, кладёт на вершину 1,
                        если значения совпадают и 0, если они разнятся
        NE       -      Сравнивает два верхних значения стека, кладёт на вершину 1,
                        если значения разные и 0, если они совпадают
        LT       -      Сравнивает два верхних значения стека, кладёт на вершину 1,
                        если верхнее значение больше нижнего и 0, если нижнее больше верхнего.
        LE       -      Сравнивает два верхних значения стека, кладёт на вершину 1,
                        если верхнее значение больше либо равно нижнему,
                        кладёт 0, если верхнее меньше нижнего.
